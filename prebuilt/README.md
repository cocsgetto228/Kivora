# Готовые бинарники

Здесь лежит собранный сервер **вместе со встроенным веб-клиентом** — чтобы
попробовать мессенджер, не устанавливая Go и Node.

| Файл                         | Платформа          |
| ---------------------------- | ------------------ |
| `kivorad-windows-amd64.exe`   | Windows 10/11, x64 |
| `kivorad-linux-amd64`         | Linux, x64         |

## Windows

Откройте PowerShell в этой папке:

```powershell
.\kivorad-windows-amd64.exe
```

Затем откройте `http://localhost:8080` и зарегистрируйтесь — первый аккаунт
становится администратором сервера.

Windows SmartScreen предупредит о неизвестном издателе: файл не подписан
сертификатом. Это ожидаемо для самостоятельно собранного приложения; при желании
пересоберите его сами командой `./build.sh server` (или `.\build.ps1` на Windows) и убедитесь, что получается тот же
результат.

Данные сложатся в подпапку `data` рядом с бинарником. Чтобы положить их в другое
место:

```powershell
$env:KIVORA_DATA_DIR = "C:\kivora-data"
.\kivorad-windows-amd64.exe
```

## Linux

```sh
chmod +x kivorad-linux-amd64
./kivorad-linux-amd64
```

# Kivora для Windows

Мессенджер со сквозным шифрованием. Один файл — `kivora.exe`. Ничего
устанавливать не нужно.

## Запуск

Двойной клик по `kivora.exe`, затем откройте `http://localhost:8080`.

Или из PowerShell, если хотите видеть журнал:

```powershell
.\kivora.exe
```

Первый созданный аккаунт становится администратором.

**SmartScreen предупредит о неизвестном издателе.** Файл не подписан
сертификатом — это ожидаемо для самостоятельно собранного приложения.
«Подробнее» → «Выполнить в любом случае». Если это вас не устраивает,
соберите его сами: исходники открыты, сборка описана в `docs/DEPLOY.md`.

## Где лежат данные

В подпапке `data` рядом с exe. Чтобы положить в другое место:

```powershell
$env:KIVORA_DATA_DIR = "C:\kivora-data"
.\kivora.exe
```

Скопируйте эту папку — это и есть резервная копия. Файл `secret.key` в ней
обязателен: без него все сессии станут недействительными.

## Чтобы подключились другие компьютеры

По умолчанию сервер слушает все интерфейсы на порту 8080. В локальной сети
достаточно разрешить его в брандмауэре:

```powershell
New-NetFirewallRule -DisplayName "Kivora" -Direction Inbound -LocalPort 8080 -Protocol TCP -Action Allow
```

Дальше коллеги открывают `http://<ваш-ip>:8080`.

**Для выхода в интернет так делать не надо.** Без TLS метаданные и токены
пойдут открыто. Сквозное шифрование сообщений при этом останется, но
поставить сервер как положено — задача отдельной поставки
`kivora-server`, там есть Caddy и nginx.

## Настольное приложение

Этот exe — сервер со встроенным веб-клиентом; интерфейс открывается в браузере.
Отдельное окно приложения (Tauri) собирается из исходников и требует Rust:

```powershell
.\build.ps1 -Task desktop
```

Сборка выдаёт установщики MSI и NSIS. Нужны Rust (MSVC), Visual Studio Build
Tools и WebView2 — в Windows 11 он уже есть, в Windows 10 доустановится сам.

## Админ-консоль

Отдельная страница по адресу `/admin`. Содержимого переписки там нет и быть не
может — на сервере сообщения зашифрованы.
